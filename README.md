Healthcare Data Analysis Capstone Project
📌 Project Overview
This Healthcare Capstone Project focuses on analyzing healthcare data to identify patient trends, hospital performance, treatment costs, and operational insights using Data Analytics techniques.

The project helps in understanding healthcare patterns and improving decision-making through data-driven analysis and visualization.

The project demonstrates:
Data Cleaning Data Analysis Exploratory Data Analysis (EDA) Dashboard Reporting Healthcare Insights Data Visualization

🎯 Problem Statement
Healthcare organizations generate large amounts of patient and hospital data daily. Analyzing this data helps improve patient care, optimize hospital operations, and reduce treatment costs.

This project aims to:

Analyze patient records Monitor hospital performance Identify treatment trends Evaluate healthcare costs Generate actionable insights

🛠️ Technologies Used
Microsoft Excel Data Analytics Data Visualization Pivot Tables Charts & Graphs

📂 Dataset Information
The dataset contains healthcare-related information such as:

Patient ID Age Gender Disease/Diagnosis Treatment Cost Hospital Department Admission Date Discharge Date Doctor Information Patient Status Medical Expenses

📋 Project Workflow
1️⃣ Data Collection
Imported healthcare dataset into Excel Organized patient and hospital records

2️⃣ Data Cleaning
Removed duplicate entries Handled missing values Corrected formatting issues Standardized column values

3️⃣ Data Analysis
Performed analysis to:

Identify patient trends Compare treatment costs Analyze department performance Monitor patient admission patterns Evaluate healthcare expenses

4️⃣ Data Visualization
Created visual reports using:

Bar Charts Pie Charts Line Charts Pivot Tables KPI Metrics

5️⃣ Insights Generation
Generated meaningful insights to support healthcare management and operational decisions.

📊 Key Insights
Certain departments handled higher patient volumes. Treatment costs varied across medical conditions. Patient admission trends changed over time. Some age groups required more medical attention. Healthcare expenses showed patterns across departments.

✅ Conclusion
This project successfully demonstrates how healthcare data can be analyzed using Excel and Data Analytics techniques. The analysis helps improve operational efficiency, patient care, and healthcare decision-making.
